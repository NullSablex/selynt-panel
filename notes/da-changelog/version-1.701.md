## Flush UnboundDNS zones during TLS certificate issuance update[​](https://docs.directadmin.com/changelog/version-1.701.html#flush-unbounddns-zones-during-tls-certificate-issuance)

TLS certificate issuance and renewal is extended to obtain up-to-date DNS records by flushing the DNS zone cache beforehand.

This functionality is available when [UnboundDNS](https://docs.directadmin.com/changelog/version-1.694.html#support-for-installing-the-unbound-dns-server) is set up as the default system resolver.

## cpanel restore: Ensure ~/.spamassassin/user_prefs permissions fix[​](https://docs.directadmin.com/changelog/version-1.701.html#cpanel-restore-ensure-spamassassin-user-prefs-permissions)

After a restore, DA will ensure the ~/.spamassassin/user_prefs file is readable by the `mail` account so exim is able to see it to decide if spam scanning should happen or not.

## cpanel restore: DNS parser logic change for improved .db reads fix[​](https://docs.directadmin.com/changelog/version-1.701.html#cpanel-restore-dns-parser-logic-change-for-improved-db-reads)

When restoring cpanel files, some casesh of DNS domain.com.db zone files have comment lines mid-file and they were not correctly handled by the DirectAdmin parser.
